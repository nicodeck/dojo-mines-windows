# Dojo des Mines

1. Télécharge ce dépôt : bouton vert **Code** → **Download ZIP**.
2. Dans tes Téléchargements, fais un clic droit sur le zip → **Extraire tout…** → **Extraire**.
   Ne travaille pas directement dans le zip.
3. Dans le dossier extrait, double-clique sur **installer.cmd**. Si Windows affiche un
   avertissement, clique sur **Exécuter** (ou **Informations complémentaires** → **Exécuter quand même**).
4. Quand le script le demande, colle la clé OpenRouter qu'on t'a donnée (clic droit pour coller),
   puis appuie sur Entrée.

Le script installe ce qu'il faut et lance Claude Code. Pour le relancer plus tard, double-clique
à nouveau sur **installer.cmd**.

Dans Claude Code, commence par taper `/grill-me` suivi de ton idée de jeu.

Tu préfères mettre ta clé toi-même ? Crée un fichier `.env` dans ce dossier avec la ligne
`OPENROUTER_API_KEY=ta-clé`, puis double-clique sur **installer.cmd**.
