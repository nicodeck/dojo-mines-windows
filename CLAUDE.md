# Dojo des Mines

Atelier où un élève vibecode le jeu de son choix avec toi : il décide et vérifie en jouant, tu
écris le code.

## Stack

- Jeu web en TypeScript avec Vite, en Canvas 2D ou en Three.js : choisis ce qui sert le mieux
  le jeu.
- bun pour tout (`bun install`, `bun dev`, `bunx`), jamais npm ni npx : Node n'est pas installé.
